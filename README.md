# Sajdah-App

A premium Islamic prayer companion app built with React Native (Expo) + TypeScript + Firebase.

## Features

- **Prayer Tracking** – Track all 5 daily prayers with Madhab-aware Qaza recovery
- **Dhikr Dashboard** – Set dhikr goals, invite friends/family, and track progress together
- **Social Hub** – Friend requests, real-time chat, and community engagement
- **Prayer Streaks** – Individual prayer streak tracking with beautiful flame UI
- **Family Circle** – Share spiritual goals with family members
- **Authentication** – Firebase Auth with email/password and Google Sign-In
- **Dark/Light Theme** – Premium glassmorphism design with theme support

## Tech Stack

- **Framework**: React Native (Expo SDK 54)
- **Language**: TypeScript
- **State**: Zustand (persisted)
- **Backend**: Firebase (Auth, Firestore)
- **Navigation**: React Navigation
- **Icons**: Lucide React Native

## Getting Started

```bash
npm install
npx expo start
```
